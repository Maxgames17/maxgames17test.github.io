Termini di Servizio - server backup

Ultimo aggiornamento: 18/09/2026

1. Accettazione dei Termini

Utilizzando questa integrazione API per Rclone, l'utente accetta di essere vincolato dai presenti Termini di Servizio. L'applicazione è progettata per un uso personale e per la gestione automatizzata di backup e file.

2. Responsabilità dell'Utente

L'utente è l'unico responsabile della configurazione del proprio client Rclone e della sicurezza delle chiavi Client ID e Client Secret generate tramite Google Cloud Console. L'amministratore dell'applicazione non è responsabile per l'eventuale perdita accidentale o cancellazione di dati derivante da errori nella configurazione dei comandi Rclone.

3. Limitazioni di Garanzia

Il servizio viene fornito "così com'è" (AS IS) senza garanzie di alcun tipo relative a tempi di operatività o disponibilità continua, dipendendo l'infrastruttura dalle API di Google Cloud.
